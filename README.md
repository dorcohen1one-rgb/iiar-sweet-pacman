# iyar / אייר · ביס קטן של אושר

A personalized candy Pacman game with three worlds, cozy and classic modes, keyboard and touch controls, and a special message for iyar.

iyar's real portrait appears inside the Pacman character and in soft circular frames on the welcome and gift screens. The screenshot is cropped in Canvas and CSS to show her smile.

Collecting candy reveals short, heartfelt compliments at least six seconds apart. A longer personal note stays visible above the maze for at least nine seconds of playing time. Floating words linger for 3.6 seconds with a gentle fade.

This repository contains the static website. No build step or dependencies are required.

Play: https://dorcohen1one-rgb.github.io/iyar-sweet-pacman/
