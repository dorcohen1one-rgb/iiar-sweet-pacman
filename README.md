# iiar / אייר · ביס קטן של אושר

A personalized candy Pacman game with three worlds, cozy and classic modes, keyboard and touch controls, and a special message for iiar.

Every candy comes with a short, heartfelt compliment for iiar. A longer personal note stays visible above the maze and rotates at a readable pace as she plays.

This repository contains the static website. No build step or dependencies are required.

Play: https://dorcohen1one-rgb.github.io/iiar-sweet-pacman/
